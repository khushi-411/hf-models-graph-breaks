# Inductor `CantSplit: ((s//16)**2)//(s//16) not divisible by (s//16)` with dynamic shapes

### System info

- torch: `2.16.0a0+git57f02f8` (source build, CUDA 12.8)
- transformers: `5.24.0.dev0` (main, git `046bdb8cc2`)
- Python 3.15, Linux; CUDA results on H100 (sm_90)

### Description

With `dynamic=True`, the backward of conv patch embedding → channels-last permute → LayerNorm → Linear fails
in Inductor on CUDA. Static shapes work, and so does the same code with smaller sizes (C=64, or a 256/512 image):

```python
import torch, torch.nn as nn

class M(nn.Module):
    def __init__(self, C=768):
        super().__init__()
        self.patch, self.ln, self.fc = nn.Conv2d(3, C, 16, 16), nn.LayerNorm(C), nn.Linear(C, C)
    def forward(self, x):
        return self.fc(self.ln(self.patch(x).permute(0, 2, 3, 1)))   # (B, S//16, S//16, C)

m, x = M().cuda(), torch.randn(2, 3, 1024, 1024, device="cuda")
torch.compile(m, dynamic=True)(x).sum().backward()
```

```
InductorError: CantSplit: ((((s53//16))**2)//((s53//16))) not divisible by (s53//16)
  torch/_inductor/codegen/simd.py: _codegen_mix_order_reduction -> split_and_set_ranges
    -> _split_iteration_ranges -> add_range
```

Full script: [`issues/repros/inductor_cantsplit_square_floordiv.py`](repros/inductor_cantsplit_square_floordiv.py).

The graph carries the width as `(a**2)//a` with `a = s//16` (`[2, a, (a**2)//a, 768]` on the reshape around
the Linear), never simplified to `a`. The LayerNorm backward is codegen'd as a mix-order reduction that
fuses the weight-grad reduction (ranges `(2*a**2,), (768,)`) with the per-row reduction (ranges
`(2, a, a, 768), ()`). Splitting the first group by `a` needs `(a**2)//a` to be divisible by `a`, which the
check can't prove from that expression.

Workaround: `torch._inductor.config.triton.mix_order_reduction = False` (verified with the repro).

Seen in Unlimited-OCR (baidu/Unlimited-OCR), SAM vision encoder, `train_forward` with `dynamic=True` on H100.
Eval and CPU are fine. (On CPU the dynamic train run instead hits the 2 h compile cap.) Model-level command:

```
python -m graph_breaks.dynamic --model unlimited_ocr --device cuda --scenario train_forward
```

### Possible fix

Simplify `FloorDiv(a**k, a)` to `a**(k-1)` for positive `a` (sizes are `>= 1`) in the sympy floordiv rules, or
let `add_range` check divisibility through `statically_known_true(Eq(Mod(expr, d), 0))` after simplification.
