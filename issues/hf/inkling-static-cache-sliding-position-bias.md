# Inkling / Inkling-2 / Inkling-2 Mini: `generate(cache_implementation="static")` fails in eager: relative position bias / mask sized from `get_mask_sizes`, keys from the static sliding-window buffer

### System info

- transformers: `5.24.0.dev0` (main, git `046bdb8cc2`)
- torch: `2.16.0a0+git57f02f8`, CPU (no compile involved)

### Description

`InklingForCausalLM.generate(..., cache_implementation="static")` fails on the first (prefill) step, in eager:

```
modeling_inkling.py:259 forward -> sdpa_attention.py:179 sdpa_attention_forward -> :86 create_position_bias_mask
RuntimeError: The size of tensor a (39) must match the size of tensor b (16) at non-singleton dimension 3
```

Config: reduced `inkling` from this repo's `models.yaml` (`sliding_window_size: 16`, `rel_extent: 16`, prompt 32
tokens, `max_new_tokens=8`). The dynamic cache works.

In `InklingAttention.forward`, `kv_length, kv_offset = cache.get_mask_sizes(q_length, layer_idx)` gives the
length the mask and the relative bias are built for (39 here), and the bias is computed for
`torch.arange(kv_length) + kv_offset`. But `cache.update()` on a static **sliding-window** layer returns its fixed
`sliding_window_size` buffer (16 keys), so `position_bias` (`[..., 39]`) and `key_states` (`[..., 16]`) disagree.

The Inkling-2 family fails the same way, in `eager_attention_forward` (`modeling_inkling2.py:534`,
`modeling_inkling2_loop.py:130`): `The size of tensor a (32) must match the size of tensor b (39) at non-singleton
dimension 3`. All five models fail (inkling, inkling2, inkling2_vlm, inkling2_mini, inkling2_mini_vlm), on CPU and
CUDA, before any compilation.

Static cache + `torch.compile(mode="reduce-overhead")` is the path transformers recommends for fast generation, so
none of the Inkling models can use it.

### Possible fix

Build `kv_positions` from what the cache layer actually returns (the sliding layer's absolute positions for its
buffer), or make the static sliding layer return keys matching `get_mask_sizes` during prefill (as the dynamic
sliding layer does). Model-level check: `python -m graph_breaks.modes --model inkling --mode generate_static`.
