# `torch.compile` graph break in Longformer / LED: `is_index_global_attn.flatten().any().item()` in every forward

### System info

- transformers: `5.24.0.dev0` (main, git `b7fe69cb19`)
- torch: `2.16.0a0+git57f02f8` (source build)
- Python 3.15, Linux; checked on CPU and on CUDA (B200)

### Description

Longformer's encoder decides in Python whether any token uses global attention
(`modeling_longformer.py:1175`); LED's encoder copies the same line (`modeling_led.py:1446`):

```python
is_index_masked = attention_mask < 0
is_index_global_attn = attention_mask > 0
# Record `is_global_attn == True` to enable ONNX export
is_global_attn = is_index_global_attn.flatten().any().item()
```

`.item()` is a host sync and a graph break (`Unsupported Tensor.item() call with
capture_scalar_outputs=False`), and `is_global_attn` then picks between two code paths in every layer.
This happens in **eval as well as train**, with or without global attention in the input.

Graph-break harness (config-only model, 2 layers, `torch._dynamo.explain`):

| model | eval_forward | eval_with_cache | train_forward |
|---|---|---|---|
| longformer | 4 graphs / 3 breaks | - | 4 / 3 |
| led | 4 / 3 | 4 / 3 | 5 / 4 |

The same break shows on CPU and CUDA. With `torch.compile(dynamic=True)` + Inductor the models also
crash in Inductor's value-range analysis (separate PyTorch issue, `inductor-bounds-truncdiv-nan`).

### Reproduction

Pattern repro: `issues/hf/repros/longformer_global_attn_item.py`

```
[original]    graphs=2 breaks=1
    - Unsupported Tensor.item() call with capture_scalar_outputs=False
[torch.where] graphs=1 breaks=0
```

### Possible fix

The two branches compute different things, so this is not a one-line change. Options:

1. Always run the global-attention computation and mask it out when no token is global
   (no Python bool needed; costs a little extra compute when there are no global tokens).
2. Use `torch.cond(is_index_global_attn.any(), global_path, local_path, ...)`.
3. Skip the `.item()` when compiling and take the general path (`is_torchdynamo_compiling()`).

### Affected

longformer, led (LED's encoder copies Longformer's attention).
